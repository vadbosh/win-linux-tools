# win-linux-tools

**Один скрипт PowerShell ставит в Windows 10/11 Linux-утилиты командной
строки: `ls`, `grep`, `sed`, `awk`, `rg`, `fd`, `jq`, `curl`, `mtr` и другие.**
Каждая утилита — отдельная программа из [Scoop](https://scoop.sh). Скрипт же
их обновляет и удаляет всё, что добавил. Без WSL, BusyBox и winget.

## Быстрый старт

1. Скачай `Install-LinuxTools.ps1` в любую папку, например `C:\Tools`.
2. Открой PowerShell в этой папке. Хватит обычного окна, не администратора.
3. Запусти:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install-LinuxTools.ps1 -LinuxFirst
   ```

4. Прочитай итог в конце. В нём — что работает, а если что-то не вышло, то
   что сделать руками.
5. Открой новое окно терминала: утилиты работают в нём.

## Правила брандмауэра для mtr

> [!IMPORTANT]
> Windows Defender Firewall отбрасывает ответы ICMP, которых ждёт `trip`, и
> `mtr` не показывает ни одного узла. Скрипт добавляет два входящих правила
> для любой программы. Они пропускают только ответы: ICMPv4 0, 3 и 11 (Echo
> Reply, Destination Unreachable, Time Exceeded) и ICMPv6 129 (Echo Reply).
> На ping компьютер по-прежнему не отвечает.
>
> Правило только для `trip.exe` не работает: ICMP, пришедший на raw-сокет,
> Windows с программой не связывает. Если прав администратора не дали, скрипт
> в конце покажет команду, которую нужно выполнить вручную. `-Uninstall`
> правила удаляет.
>
> Только эти правила, без остального скрипта, ставит
> `tools\Enable-TripFirewall.ps1`; `-Remove` их удаляет.

## Два режима: с -LinuxFirst и без

> [!IMPORTANT]
> **`-LinuxFirst` — это режим, а не дополнительный набор утилит.** Утилиты в
> обоих режимах ставятся одни и те же. Режим решает, какая программа
> откроется по имени, которое в Windows уже занято: `ls`, `rm`, `find`,
> `curl`, `sort`.

| Набираешь | Без `-LinuxFirst`, PowerShell | Без `-LinuxFirst`, cmd | С `-LinuxFirst`, PowerShell и cmd |
|---|---|---|---|
| `ls -la` | ошибка: `ls` — это `Get-ChildItem` PowerShell | Linux `ls` | Linux `ls` |
| `rm -rf dir` | ошибка: `rm` — это `Remove-Item` PowerShell | Linux `rm` | Linux `rm` |
| `curl` | `Invoke-WebRequest` PowerShell | `curl.exe` Windows | Linux `curl` |
| `wget` | `Invoke-WebRequest` PowerShell | Linux `wget` | Linux `wget` |
| `find . -name "*.log"` | ошибка: `find.exe` Windows ищет текст | ошибка: `find.exe` Windows ищет текст | Linux `find` |
| `sort`, `more`, `timeout`, `whoami`, `hostname` | программы Windows или команды PowerShell | программы Windows | Linux-утилиты |
| `cat a.txt \| sort` — имя из Windows после `\|` или `&` | `Sort-Object` PowerShell | `sort.exe` Windows | PowerShell: Linux `sort`. cmd: Linux `sort` с [clink](#cmd-и-clink), без него — `sort.exe` Windows |
| `grep`, `sed`, `awk`, `rg`, `fd`, `jq`, `bat`, `ll`, `mtr` | Linux-утилиты | Linux-утилиты | Linux-утилиты |
| Серая подсказка из истории при наборе | нет | нет | PowerShell: да. cmd: только с [clink](#cmd-и-clink) |
| Что меняется в оболочках | ничего | ничего | блок в профиле PowerShell, макросы doskey в cmd |

**Бери `-LinuxFirst`**, если набираешь Linux-команды руками. **Не бери**, если
привык к `ls` и `rm` из PowerShell и к `find` из Windows или хватает имён,
которые ни с чем не совпадают.

Как это устроено: в PowerShell блок в профиле делает из каждого имени
небольшую функцию, если его Linux-утилита установлена. Набранная команда
запускает Linux-утилиту. То же имя в скрипте или в модуле Windows запускает
то, что запускало раньше: `sort` — `Sort-Object`, `find` — `find.exe` из
Windows. В cmd то же делают макросы doskey: они срабатывают только на
набранное.
Ещё PowerShell показывает серым продолжение подходящей команды из истории;
стрелка вправо её принимает. В Windows PowerShell 5.1 встроен PSReadLine
2.0, он так не умеет, поэтому скрипт ставит свежий PSReadLine с PSGallery
для твоего пользователя. Свой PSReadLine 2.1+ скрипт не трогает.
Ещё с `-LinuxFirst` [posh-git](https://github.com/dahlbyk/posh-git)
показывает в приглашении ветку и изменения git, а команды git дополняет по
Tab. [fzf](https://github.com/junegunn/fzf) с
[PSFzf](https://github.com/kelleyma49/PSFzf) добавляет две клавиши: Ctrl+R —
нечёткий поиск по всей истории, Ctrl+T — поиск файла с вставкой пути.

История работает как в bash с `HISTSIZE=999999`, `ignorespace` и
`HISTIGNORE='ls:ll:la:pwd:exit:history:clear'`. Она хранит 999999 команд.
Команда, которая начинается с пробела, не сохраняется, как и строка, которая
целиком совпадает с одной из этих команд; `ls -la` сохраняется. Стрелки не
покажут повтор дважды, но в файле истории он остаётся. `history`
выводит всю сохранённую историю с номерами, `history 20` — последние 20.
Время выполнения команд PowerShell не записывает, поэтому его нет.

Скрипты (`.ps1`) и модули Windows работают как без `-LinuxFirst`, даже если
запустить их из этого окна. Включить режим позже — снова запустить скрипт с `-LinuxFirst`. `-Uninstall` убирает и блок,
и макросы.

### cmd и clink

[clink](https://chrisant996.github.io/clink/) не обязателен.
Без него макрос doskey срабатывает только на первом слове строки: в
`dir | sort` или `cd x & find . -name a` запустятся `sort.exe` и `find.exe` из
Windows. Это касается только имён, которые есть и в Windows (`find`, `sort`,
`more`, `timeout`, `whoami`, `hostname`, `curl`); остальные утилиты работают в
любом месте строки. С clink макросы работают и после `|` и `&`. Без него —
полный путь: `dir | %USERPROFILE%\scoop\shims\sort.exe`.

Серых подсказок в cmd без clink нет. Свои клавиши истории у cmd: F8
дополняет набранное начало из истории (ещё F8 — более ранние совпадения),
F7 показывает список. `-WithClink` ставит clink из Scoop, запускает его с
каждым окном cmd (`clink autorun install`), включает серые подсказки
(`autosuggest.enable`) и клавиши Windows (`clink.default_bindings windows`,
как делает установщик clink с enhanced defaults). При старте cmd clink
печатает вместо copyright одну короткую строку с версией
(`clink.logo short`); убрать и её — `clink set clink.logo none`.

История в clink тоже настроена как в bash: 999999 строк, строки с пробелом в
начале не сохраняются, повторов нет (`erasedups`), а `history` показывает
время каждой команды (`%F %T`). В отличие от bash, clink сверяет
`ls ll la pwd exit history clear` с первым словом, поэтому `ls -la` тоже не
сохраняется.

Клавиши в clink:

- стрелка вправо принимает серую подсказку, F2 показывает все подсказки
  списком;
- стрелки вверх и вниз листают историю по набранному началу;
- Tab подставляет в строку следующее подходящее имя команды или файла,
  Shift+Tab — предыдущее, как в PowerShell.

Стрелки вверх и вниз, Tab и Shift+Tab скрипт дописывает в `.inputrc`. Свой
clink, который уже запускается с cmd, скрипт не трогает.

## Ключи

| Ключ | Что делает |
|---|---|
| *(без ключа)* | Ставит основные утилиты. Уже установленные не трогает. |
| **`-LinuxFirst`** | **Режим.** Ставит утилиты, и в PowerShell и cmd Linux-имена побеждают имена Windows: [подробно](#два-режима-с--linuxfirst-и-без). |
| `-WithFar` | Дополнительно ставит Far Manager с плагинами, тёмной темой и настройками: [подробно](#far-manager). |
| `-WithNmap` | Дополнительно ставит `nmap` и `ncat` (`nc`) с драйвером Npcap. |
| `-WithOhMyPosh` | Дополнительно ставит oh-my-posh с темой приглашения, которой не нужен особый шрифт: [`themes/install-linuxtools.omp.json`](themes/install-linuxtools.omp.json). Поправь её и запусти `-Update`, чтобы применить. Если стоит и `-WithClink`, то же приглашение будет в cmd: [`themes/oh-my-posh.lua`](themes/oh-my-posh.lua) кладётся в `%LOCALAPPDATA%\clink`. Другие темы oh-my-posh рисуют значки, им нужен [Nerd Font](https://www.nerdfonts.com/font-downloads), выбранный в терминале. |
| `-WithClink` | Дополнительно ставит [clink](#cmd-и-clink) для cmd: серые подсказки из истории, макросы после `\|` и `&`. |
| `-Update` | Обновляет Scoop и все утилиты, которые поставил скрипт, и плагины Far. Доставляет утилиты, добавленные в скрипт позже. |
| `-Uninstall` | Удаляет то, что добавил скрипт. git, Visual C++ и Npcap остаются. |
| `-Uninstall -WithFar`, `-WithNmap`, `-WithClink`, `-WithOhMyPosh` | Удаляет только это дополнение. Остальное остаётся. |
| `-Help`, `--help` | Показывает справку. |

Без `-WithFar`, `-WithNmap` и `-WithClink` Far, nmap и clink не ставятся. Любой из этих ключей
можно добавить когда угодно: поставленное раньше не удаляется, остальные ключи
повторять не нужно. `-Update` Far и nmap не добавляет.

## Какую команду запускать

| Что нужно | Команда |
|---|---|
| Linux-утилиты, команды Windows остаются как есть | `.\Install-LinuxTools.ps1` |
| Набирать руками `ls -la`, `rm -rf`, `find . -name` | `.\Install-LinuxTools.ps1 -LinuxFirst` |
| Двухпанельный файловый менеджер, как mc | `.\Install-LinuxTools.ps1 -WithFar` |
| Сканирование портов и netcat | `.\Install-LinuxTools.ps1 -WithNmap` |
| Всё сразу | `.\Install-LinuxTools.ps1 -LinuxFirst -WithFar -WithNmap` |
| Новые версии и утилиты, добавленные в скрипт позже | `.\Install-LinuxTools.ps1 -Update` |
| Удалить только Far или только nmap | `.\Install-LinuxTools.ps1 -Uninstall -WithFar`, `-Uninstall -WithNmap` |
| Удалить всё | `.\Install-LinuxTools.ps1 -Uninstall` |

Если запуск скриптов запрещён или ты в cmd, начинай каждую команду с
`powershell -ExecutionPolicy Bypass -File`.

| `grep` | Искать текст в файлах по регулярному выражению |
| `awk` | Работать со столбцами текста: выбрать поля, сложить числа, переформатировать |
| `sed` | Заменять текст в потоке или файле |
| `less` | Листать длинный вывод и искать в нём |
| `jq` | Читать, фильтровать и перестраивать JSON |
| `which` | Показать, какой файл запускает команда |
| `rg` (ripgrep) | Быстрый поиск по коду во всех вложенных папках; пропускает файлы из `.gitignore` |
| `ug`, `ugrep` | grep с теми же ключами, плюс поиск внутри архивов (`-z`) и интерактивный режим (`-Q`) |
| `fd` | Быстрый и простой `find`: `fd имя` |
| `lsd` | `ls` с цветами и понятными столбцами |
| `eza`, `ll` | Ещё один современный `ls`: дерево (`--tree`), состояние файлов в git; `ll` — подробный список |
| `bat` | `cat` с подсветкой синтаксиса и номерами строк |
| `dust` | Какие папки занимают место — в виде диаграммы |
| `gdu` | Занятое место: можно ходить по папкам и удалять лишнее, как в ncdu; скрипт задаёт цвета и проценты рядом с полоской |
| `duf` | Свободное место на всех дисках таблицей (`df`) |
| `btm` (bottom) | `top` с графиками: процессор, память, сеть, процессы |
| `procs` | `ps` с понятными столбцами и поиском |
| `sudo` (gsudo) | Выполнить одну команду от администратора в том же окне |
| `dig`, `host` | Запросы к DNS |
| `trip`, `mtr` | traceroute и ping на одном обновляемом экране |
| `whois` | Кому принадлежит домен или IP-адрес |
| `xh` | HTTP-запросы с читаемым выводом, как HTTPie |
| `curl` | Свежий curl; встроенный в Windows curl.exe остаётся |
| `wget` | Скачать файлы, докачать оборванное, скопировать сайт |
| `git` | Нужен Scoop для обновления; полноценный git, им можно пользоваться |
| `nmap`, `nping` | Сканирование портов и узлов *(с `-WithNmap`)* |
| `ncat`, `nc` | Чтение и запись сетевых соединений, netcat *(с `-WithNmap`)* |
| `far` | Двухпанельный файловый менеджер, как mc *(с `-WithFar`)* |
| `clink` | Строка cmd как в bash *(с `-WithClink`)* |
| `oh-my-posh` | Двухстрочное приглашение PowerShell `┌──user@host [папка] \| ветка` / `└─>` в цветах Material, набираемая команда ярче; особый шрифт не нужен *(с `-WithOhMyPosh`)* |

`Get-Help .\Install-LinuxTools.ps1 -Full`.

## Короткие имена

Работают в PowerShell и cmd, и без `-LinuxFirst` тоже.

| Имя | Что запускает |
|---|---|
| `ll` | `eza -la --classify --git --smart-group --group-directories-first --time-style "+%F %R:%S"` |
| `mtr` | `trip` через gsudo: ему нужны права администратора, он их запросит |
| `nc` | `ncat` |
| `nmap`, `nping` | их же, через gsudo *(с `-WithNmap`)* |
| `far` | Far открывается в текущей папке. После выхода из Far оболочка остаётся в папке, где был Far *(с `-WithFar`)* |

`ll` показывает сначала папки, потом файлы: атрибуты, размер, дату и время
до секунды, состояние git (`-M`, `N-` и т. п. внутри репозитория), имя. `/`
после имени — папка, `*` — программа. У папок размера нет: на Windows eza не
считает размер папки (`--total-size` работает только в Unix); размер папок
смотри в `dust` или `gdu`.

## Цвета файлов

`ll`, `eza`, `ls` и `fd` раскрашивают имена по типу. Без настройки папки идут
тёмно-синим цветом консоли `#0037DA`, и их плохо видно. Скрипт задаёт для
твоего пользователя `LS_COLORS` и `EZA_COLORS`: папки и типы файлов хорошо
читаются. Ссылки — на бирюзовом фоне; `ll` показывает их как
`имя -> цель`, `lsd -l` — как `имя ⇒ link to цель`.

Своё значение, заданное раньше, скрипт не трогает. Новые цвета видны в новых
окнах; для cmd иногда нужно выйти из Windows и войти снова.

## Far Manager

С `-WithFar` скрипт ставит Far Manager и настраивает его:

- **Плагины.** NetBox (SFTP, FTP, SCP, WebDAV, S3) и IntChecker2
  (контрольные суммы). Оба — из последнего релиза на GitHub, с проверкой
  SHA-256. ArcLite (архивы) и FarColorer (подсветка синтаксиса) идут с самим
  Far.
- **Тема.** FarDark-2026, закреплена на одном коммите и сверена по хешу.
  В файлах темы цвета записаны в неверном порядке байтов; скрипт их
  переставляет, и папки выходят голубыми, а не оранжевыми.
- **Цвета ярче.** Курсор на панели `#4B5263`, номера строк в редакторе
  `#275A65`, строка состояния редактора `#124B55`, текущая строка в
  редакторе `#3A3D41`.
- **Настройки.** 24-битный цвет (VT), сохранение настроек при выходе, стиль
  FarColorer TrueMod. В редакторе (F4): номера строк, полоса прокрутки,
  автоотступ, Tab пробелами, курсор не уходит за конец строки.
- **Папка после выхода.** `far` открывается в текущей папке, а после выхода
  PowerShell или cmd остаётся в папке, где был Far, — как `mc` в Linux.
- **Backspace — на папку вверх** на панели, когда командная строка пуста,
  как в mc (макрос Far; то же делает Ctrl+PgUp).
- **Ярлыки на рабочем столе.** `Far4Pwsh` открывает PowerShell, `Far4CMD` —
  cmd; оба запускают Far. После выхода из Far (F10) окно остаётся открытым в
  папке, где был Far.

Прежние значения скрипт сохраняет, `-Uninstall` их возвращает. Папку плагина
или ярлык на рабочем столе, созданные не им, скрипт не трогает. `-Update`
обновляет Far и плагины; пока Far запущен, сам Far не обновляется.

## Что ещё делает скрипт

- **Недостающие DLL.** После каждого пакета скрипт читает из программ, какая
  среда Visual C++ им нужна, скачивает у Microsoft Visual C++ 2015–2022 нужной
  разрядности, проверяет подпись и ставит. Без x64-версии большинство утилит
  не запускается: если поставить её не вышло, скрипт останавливается, ничего
  больше не меняя.
- **Npcap.** Для `-WithNmap` открывает установщик Npcap из пакета nmap,
  проверив подпись.
- **Лог.** Каждый запуск пишет весь вывод в
  `Install-LinuxTools_<дата-время>.log` рядом со скриптом.
- **Итог.** В конце: что работает, что не запускать, предупреждения без
  повторов и по порядку — что сделать руками.
- **Учёт изменений.** Что добавил скрипт, записано в
  `%LOCALAPPDATA%\Install-LinuxTools\state.json`. По нему работает
  `-Uninstall`.

## Для пользователя, а не для компьютера

Скрипт меняет только окружение того пользователя Windows, который его
запустил:

| Что | Где |
|---|---|
| Scoop и утилиты | `%USERPROFILE%\scoop` или `%SCOOP%`, если переменная задана |
| `PATH`, `LS_COLORS`, `EZA_COLORS` | переменные среды пользователя |
| Блок PowerShell, функция `far` | файлы `profile.ps1` в папке «Документы» пользователя |
| Макросы cmd | `AutoRun` в `HKCU\Software\Microsoft\Command Processor` |
| Настройки, плагины и тема Far | `persist\far` в папке Scoop |
| Ярлыки Far | рабочий стол пользователя |
| PSReadLine, posh-git, PSFzf (с `-LinuxFirst`) | `WindowsPowerShell\Modules` в папке «Документы» пользователя |
| Запуск clink с cmd | `AutoRun` в `HKCU\Software\Microsoft\Command Processor` |
| Клавиши clink | блок с метками в `%USERPROFILE%\.inputrc` или в твоём `.inputrc` |
| Цвета gdu | `%USERPROFILE%\.gdu.yaml` (только если своего нет) |
| Настройки lsd | `%APPDATA%\lsd\config.yaml` |
| Политика выполнения | область `CurrentUser` |
| Учёт изменений | `%LOCALAPPDATA%\Install-LinuxTools\state.json` |

Другие пользователи компьютера ничего из этого не получают. Каждый запускает
скрипт в своей учётной записи и получает свою копию и свои настройки.
Администратор может запустить программу по полному пути, например
`C:\Users\<user>\scoop\apps\far\current\Far.exe`, но команды и
настройки из таблицы у него не появятся.

Три исключения действуют на весь компьютер и требуют прав администратора:
среда Visual C++ 2015–2022, драйвер Npcap и правила брандмауэра для `mtr`.
`-Uninstall` оставляет первые два и удаляет правила.

## Обновление и удаление

`-Update` обновляет Scoop, все утилиты, которые поставил скрипт, плагины и
тему Far и доставляет утилиты, добавленные в скрипт позже.

`-Uninstall` удаляет только то, что добавил скрипт:

- его пакеты;
- Scoop, если его поставил скрипт и других пакетов в нём не осталось;
- блок в профиле PowerShell, макросы cmd и поставленные им модули PowerShell;
- clink, его запуск с cmd, его настройки и история (`%LOCALAPPDATA%\clink`);
- цвета, настройки, плагины и ярлыки Far;
- правила брандмауэра для `mtr`;
- изменение политики выполнения.

`-Uninstall -WithFar` удаляет только Far: пакет, его плагины, тему,
настройки, ярлыки на рабочем столе и переход в папку Far после выхода.
`-Uninstall -WithNmap` удаляет только nmap и ярлык `nc`. `-Uninstall
-WithClink` удаляет clink полностью: пакет, его запуск с cmd, его клавиши в
`.inputrc`, настройки и историю; clink, который был до скрипта, остаётся.
Настройки и история сначала копируются в `backup\clink_<дата-время>` рядом
со скриптом (в `%TEMP%`, если эта папка только для чтения). В истории могут
быть пароли из набранных команд, поэтому `backup\` внесён в `.gitignore`.
Вернуть их — снова
запустить скрипт с `-WithFar` или `-WithNmap`.

Прежде чем что-то менять, `-Uninstall` проверяет, не запущен ли Far и нет ли
окон cmd с clink: они держат файлы, поэтому скрипт останавливается и просит
их закрыть. Запускай его из PowerShell. Это окно PowerShell само держит
PSReadLine и PSFzf; они удаляются, когда ты закроешь окно.

После полного `-Uninstall` остаются:

- **git**: он может быть нужен твоим репозиториям. Удалить —
  `scoop uninstall git`.
- **Visual C++ и Npcap**: они могут быть нужны другим программам.

## Требования

Windows 10 или 11 и Windows PowerShell 5.1 (встроен). Доступ в интернет к
GitHub, Scoop и Microsoft. Права администратора запрашивают установщики
Visual C++ и Npcap и добавление правил брандмауэра для `mtr`.

Проверено на двух машинах. На Windows 11 под учётной записью без прав
администратора работают:

- установка со всеми ключами, `-Update`, `-Uninstall` и удаление каждого
  дополнения;
- ярлыки `Far4Pwsh` и `Far4CMD`;
- серые подсказки в PowerShell и в cmd с clink, posh-git, fzf, oh-my-posh;
- `mtr`, `nmap` и `nping` через gsudo;
- переход в папку Far после выхода в PowerShell и cmd.
